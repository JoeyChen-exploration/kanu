# 卡奴美术需求表

2026-11-18 定：美术由我们自己做，不再交给服主。这份表列出要画什么、什么规格、先做哪些，以及做好的图放在哪、怎么命名，方便以后直接接进游戏。

## 总体要求

- **风格**：反乌托邦空间站下层区，霓虹、赛博朋克、旧货店的感觉。不要做成文字游戏：柜台、库存、开包都要有画面。
- **横屏**：卡奴是横屏游戏，主要在手机横屏（约 844 × 390）和电脑 16:9 上看。场景背景、界面底图按横版画。
- **格式**：WebP（要透明的用带透明通道的 WebP 或 PNG），单张不超过 150 KB。所有图由卡奴服务器自己托管，不引用外部链接。
- **分层，能复用就复用**：卡面和卡框分开画，每张卡只画一次卡面，6 套卡框由前端叠加，所以是"100 幅卡面 + 6 套卡框"，不是 100 × 6 张。放大镜看到的细节也是一套通用贴图，所有卡共用（见下）。
- **优先级**：MVP = 第一版内测就要；后期 = 以后的版本，不急。

## 先做哪些

想尽快让游戏"有画面"，建议按这个顺序：

1. 场景背景（柜台、台面）+ 卡背 + 5 种卡包包装：一打开就能看到。
2. 4 套卡框 + 稀有度角标 + 放大镜和电话：卡牌和道具的样子立起来。
3. 卡面插画：先每个系列画 SR 以上的几张（玩家最在意开到的好卡），N / R 可以晚一点。
4. 顾客头像、放大镜细节贴图、磨损、封壳。
5. 其余。

## 做好的图放在哪

放进仓库的 `packages/client/public/art/`，按下面的名字命名，前端会按名字去找：

| 类别 | 路径和命名 |
| --- | --- |
| 卡面 | `art/cards/<卡编号>.webp`，如 `art/cards/NEO-01.webp`（卡编号见 `packages/server/content/series/*.json`） |
| 卡框 | `art/frames/<风格>.webp`：`standard` `holo` `ice` `gold` `dark` `serial` |
| 稀有度角标 | `art/rarity/<稀有度>.webp`：`N` `R` `SR` `SSR` `UR` `LR` `MR` |
| 卡包包装 | `art/packs/<系列编号>.webp`、整盒 `art/packs/<系列编号>-box.webp` |
| 顾客头像 | `art/customers/<类型>-<序号>.webp`，如 `art/customers/rich-1.webp`（类型名见 `balance.ts` 的 `CUSTOMER_TYPES`） |
| 放大镜细节 | `art/loupe/<名字>.webp`：`halftone` `ink` `misregister` `holo` `border` `scratch` `dust` `gap` |
| 磨损 | `art/wear/<档位>.webp`：`1`（落灰）`2`（划痕）`3`（卷角） |
| 其他 | `art/ui/`、`art/scenes/`、`art/items/`、`art/binders/` 下按中文意思起英文名，接入时再对照 |

现在界面上都是代码画的占位。每类图到了以后，前端换成读图片：卡面和卡框改 `Card.tsx`，放大镜细节改 `style.css` 里"放大镜细节：美术接入点"那一段（只换 `background`，其他代码不动）。
