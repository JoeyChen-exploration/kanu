# 卡奴美术需求表

2026-11-18 定：美术由我们自己做，不再交给服主。这份表列出要画什么、什么规格、谁来做、先做哪些，以及做好的图放在哪、怎么命名、怎么验收。

## 总体要求

- **风格**：反乌托邦空间站下层区，霓虹、赛博朋克、旧货店的感觉。不要做成文字游戏：柜台、库存、开包都要有画面。
- **配色**：沿用 Activity 图标（暗物质 K），界面和卡框是一套视觉。具体色值放在 `art-src/palette.json`：深底 `#030207 → #0d0619 → #241046`（径向渐变，中心亮），霓虹描边 `#b48cff`，外发光 `#4a1fd1`，高光 `#e6d7ff`，金框 `#fff3c4 → #e8b84a → #8a5a12 → #f7d77a`，镭射 `#7cf7ff → #b99bff → #ff8ad8 → #ffe28a`。标志字体 Unbounded 900。
- **横屏**：卡奴是横屏游戏，主要在手机横屏（约 844 × 390）和电脑 16:9 上看。场景背景、界面底图按横版画。
- **格式**：WebP（要透明的用带透明通道的 WebP 或 PNG）。体积上限：场景 300 KB，其余 150 KB。所有图由卡奴服务器自己托管，不引用外部链接。
- **分层，能复用就复用**：卡面和卡框分开画，每张卡只画一次卡面，6 套卡框由前端叠加，所以是"100 幅卡面 + 6 套卡框"，不是 100 × 6 张。放大镜看到的细节也是一套通用贴图，所有卡共用（见下）。
- **优先级**：MVP = 第一版内测就要；后期 = 以后的版本，不急。

## 谁来做

- **代码**：仓库这边用 SVG 生成脚本出图（`scripts/art/build.mjs`，`npm run art:build`），SVG 源码存在 `art-src/svg/`，改颜色改 `art-src/palette.json` 后重跑。
- **AI**：claude.ai 上的美术负责写 Draw Things 提示词，Joey 在 Mac 上出图，挑好的原图放进网盘的原图目录，仓库这边 `npm run art:import` 接进来（见"做好的图放在哪"）。

## 卡面安全区

卡牌在游戏里按 **630 × 880** 为基准排版，所有位置都按卡宽的比例换算（`style.css` 卡牌一段用容器单位写，1% 卡宽 = 6.3 px），所以不管卡显示多大，下面这些像素值都准。卡框的镂空、卡面构图都照这张表；改了要同时改 `style.css`、`art-src/palette.json` 的 `layout`。

| 区域 | 位置（x, y 从左上角起，单位 px） | 说明 |
| --- | --- | --- |
| 整张卡 | 0, 0 – 630, 880，外圆角 28 | 卡面图画满整张 |
| 外框带 | 四周 24 px | 被卡框盖住，卡面图这一圈只要有颜色延续就行 |
| 卡面窗口 | 24, 24 – 606, 856，圆角 20 | 透过卡框看到的卡面 |
| 稀有度角标 | 40, 40 – 160, 160（120 × 120） | 左上，盖在卡面上 |
| 序列号 | 430, 48 – 590, 108（160 × 60） | 右上，只有编号限定卡有 |
| 拒评印章 | 480, 116 – 590, 156 | 右上，序列号下面，只有被拒评的卡有 |
| 名牌条 | 24, 704 – 606, 856（高 152） | 卡框画半透明深色底；卡名在 716–772，标签在 780–812 |
| 风格标签 | 476, 818 – 590, 848 | 名牌条右下，"闪卡""金框"之类 |
| "批"字标记 | 36, 800 – 84, 848 | 名牌条左下，批发来的卡才有 |
| **主体安全区** | **60, 176 – 570, 690** | 人物、物件、脸都放在这里面，不会被角标和名牌条挡住 |

小卡（卡册格子里约 90 px 宽）不显示标签和风格标签，只有卡名，其余位置不变。

## 先做哪些

想尽快让游戏"有画面"，建议按这个顺序：

1. 场景背景（柜台、台面）+ 5 种卡包包装：一打开就能看到。（卡背已生成）
2. 道具（放大镜、电话）。（4 套卡框 + 稀有度角标已生成）
3. 卡面插画：先每个系列画 SR 以上的几张（玩家最在意开到的好卡），N / R 可以晚一点。
4. 顾客头像。（放大镜细节、磨损已生成）
5. 其余。

## 做好的图放在哪

成品放在仓库的 `packages/client/public/art/`，按下面的名字命名，前端会按名字去找：

| 类别 | 路径和命名 |
| --- | --- |
| 卡面 | `art/cards/<卡编号>.webp`，如 `art/cards/NEO-01.webp`（卡编号见 `art-src/cards.json`）；卡背 `art/cards/back.webp` |
| 卡框 | `art/frames/<风格>.webp`：`standard` `holo` `ice` `gold` `dark` `serial` |
| 稀有度角标 | `art/rarity/<稀有度>.webp`：`N` `R` `SR` `SSR` `UR` `LR` `MR` |
| 卡包包装 | `art/packs/<系列编号>.webp`、整盒 `art/packs/<系列编号>-box.webp` |
| 顾客头像 | `art/customers/<类型>-<1~3>.webp`，如 `art/customers/rich-1.webp`（类型名见 `balance.ts` 的 `CUSTOMER_TYPES`，送货员是 `courier`） |
| 科技树联系人 | `art/contacts/<id>.webp`（id 见上表） |
| 放大镜细节 | `art/loupe/<名字>.webp`：`halftone` `ink` `misregister` `holo` `border` `scratch` `dust` `gap` |
| 磨损 | `art/wear/<档位>.webp`：`1`（落灰）`2`（划痕）`3`（卷角） |
| 品牌 | `art/brand/`，如 `art/brand/icon-1024.png` |
| 其他 | `art/scenes/` `art/ui/` `art/items/` `art/binders/` `art/collection/` `art/showcase/` `art/tech/` `art/logos/`，文件名用小写英文、数字、短横线 |

**AI 图的流程（Mac 出图 → Windows 接入）**：

1. Joey 在 Mac 上用 Draw Things 出图，挑好的**原图（PNG）**放进网盘同步的原图目录。目录结构、文件名和 `public/art/` 一一对应，只是扩展名是 `.png`：`cards/NEO-01.png` → `art/cards/NEO-01.webp`。每张图的提示词记在原图目录的 `prompts.csv`（表头 `file,model,prompt,negative,seed,steps,size,date`）。
2. Windows 这边在 `.env` 里写 `ART_RAW_DIR=<原图目录>`（见 `.env.example`），跑 `npm run art:import`：
   - 只处理新增或改过的原图（比较修改时间）；
   - 按规格处理：卡面居中裁成 63:88 再缩到 630 × 880，顾客头像、联系人缩到 256 × 256，场景缩到 1920 × 1080，卡包包装等比缩到 630 × 880 以内；
   - 转 WebP，质量从 85 往下试，直到满足体积上限（场景 300 KB，其余 150 KB）；
   - `prompts.csv` 复制一份到 `art-src/prompts.csv`（进 git）；原图本身不进 git；
   - 处理完自动跑 `npm run art:check`，打印新增了哪些图、哪些超标或命名不对。
3. 看一眼游戏里的效果，提交 `public/art/` 和 `art-src/prompts.csv`。

**代码图的流程**：改 `scripts/art/build.mjs` 或 `art-src/palette.json`，跑 `npm run art:build`，SVG 源码进 `art-src/svg/`、成品进 `public/art/`。

**缺图时**：前端每类图加载失败都回退到现在代码画的占位，不报错，所以可以一张一张地放。已经接图的：卡面、卡框、稀有度角标、卡背、卡包包装（含整盒）、顾客头像、放大镜细节、磨损。场景、道具、卡册、图鉴册、珍藏柜、联系人、UI 图标等图到了再接（代码里还是占位）。

## 验收（`npm run art:check`）

检查 `packages/client/public/art/` 里的每张图，有问题退出码 1：

- 只收 `.webp` / `.png`，扩展名要和文件内容一致；同一张图 `.webp` 和 `.png` 只能留一个。
- 必须放在 `art/<类别>/` 下面一层，类别和文件名按上面"做好的图放在哪"：卡编号要在 `art-src/cards.json` 里，顾客类型要在 `CUSTOMER_TYPES` 里，风格、稀有度、放大镜细节、联系人只能是表里那几个名字。
- 尺寸：卡面、卡背、卡框、磨损 630 × 880；稀有度角标正方形；顾客头像、联系人、放大镜细节 256 × 256；卡包包装竖版；场景横版、至少 1920 × 1080。
- 透明通道：卡框、稀有度角标、放大镜细节、磨损、UI 图标、道具、科技树图标、Logo 必须带。
- 体积：场景 ≤ 300 KB，品牌 ≤ 600 KB，其余 ≤ 150 KB。
- 最后打印 MVP 各类图的进度（比如"卡面 12 / 100"）。
