# 给美术的资料（2026-11-25）

claude.ai 美术要的写卡面提示词用的资料。卡名、标签、卡面文字现在都是**占位**，可以改；编号不变，图按编号命名。

## 1. 世界观

一座反乌托邦空间站的下层区。玩家在这里经营一间卡牌店：抽卡进货、鉴定真伪、卖给顾客、交每周上涨的摊位费，最终买下整间店。上层区是有钱人住的地方，下层区霓虹、潮湿、拥挤，黑市和治安局都在。

## 4. 顾客类型

文件名 `art/customers/<类型>-<1~3>.webp`。

| 类型名 | 中文 | 出现率 | 设定 |
| --- | --- | --- | --- |
| `resident` | 下层区居民 | 19% | 买 N / R，经常只拿得出一半的钱 |
| `student` | 学生 | 10% | 零花钱少、耐心好，喜欢闪闪的特殊风格卡 |
| `tourist` | 观光客 | 10% | 上层区来的游客，不太懂行，给钱爽快 |
| `collector` | 收藏家 | 12% | 只看 SR 以上和高分封壳卡，眼睛毒，容易看穿假卡 |
| `nostalgic` | 怀旧老顾客 | 8% | 点名找小时候丢掉的那一张，找到了出价很高 |
| `rich` | 上层区富人 | 10% | 很少验货，"价钱不是问题" |
| `speculator` | 炒卡客 | 8% | 几乎不肯多给、没耐心，只为囤货赚差价 |
| `streamer` | 开箱主播 | 8% | 买没拆的卡包回去直播开箱 |
| `middleman` | 黑市中间人 | 10% | 只收赃卡和没验过的卡，价钱他说了算 |
| `grand` | 大藏家 | 珍藏柜够好才来 | 上层区的大人物，出价最高，私人收藏室 |
| `courier` | 送货员（货郎七号） | 电话批发到货时 | 物流站的搬运机器人，和科技树联系人 `courier7` 是同一个形象 |
| `dealer` | 卡贩 | 后期 | 反过来卖卡给玩家，来路不明 |
| `undercover` | 便衣治安员 | 后期 | 伪装成其他类型，**不用单独画** |
