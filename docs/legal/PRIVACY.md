# 卡奴（KANU）隐私政策

生效日期：2026 年 11 月 17 日

卡奴（KANU）是一款在 Discord 里运行的卡牌经营小游戏（Discord Activity），由个人开发者开发和维护，只在"大洋洲玩家游戏社区"Discord 服务器内提供。本政策说明卡奴收集哪些信息、怎么用、存多久，以及你可以怎么处理自己的数据。

## 1. 收集哪些信息

**你授权后从 Discord 获取的信息**（OAuth2 范围：`identify`、`guilds`）

- Discord 用户 ID、用户名或显示名、头像；
- 你加入的服务器列表：**只用来确认你是不是大洋洲玩家游戏社区的成员，不保存**。

**你玩游戏产生的数据**

- 信用点、信誉、卡牌和库存、鉴定结果、科技树进度、顾客交易、兑换记录等游戏数据；
- 操作日志（什么时候做了什么、信用点怎么变动），用来排查问题、对账和防作弊。

卡奴**不收集**：邮箱、手机号、真实姓名、位置、聊天内容、语音内容，不使用 Cookie 做追踪，不接入任何广告或第三方统计。

## 2. 怎么使用

- 让你登录并保存游戏进度；
- 运行游戏规则（开包、交易、房租、排行榜等）；
- 在服务器频道里播报游戏事件（例如开出稀有卡时显示你的显示名和卡名），以及给你发游戏相关的私信（例如交租提醒）；
- 排查错误、对账、防止作弊。

## 3. 和谁共享

- **旺财（服务器机器人）**：查询你的服务器金币余额、把你兑换的信用点换成服务器金币时，卡奴会把你的 Discord 用户 ID 和兑换数量发给旺财。旺财由服务器运营方管理，它对金币数据的处理遵循服务器的规则。
- **Discord**：卡奴通过 Discord 的接口登录、发播报和私信，Discord 按它自己的[隐私政策](https://discord.com/privacy)处理这些数据。
- 除此之外，卡奴**不出售、不出租、不分享**你的数据给任何人。法律要求时除外。

## 4. 存在哪里、存多久

- 数据存在卡奴的服务器上（和服务器运营方的机器人运行在同一台机器上），只有开发者和受托的服务器管理员能访问。
- 游戏数据在卡奴运行期间保存；每个赛季结束时，信用点、库存等进度会按游戏规则重置，但历史头衔、图鉴等收藏记录和操作日志会保留。
- 数据库每天备份，备份保留 14 天。

## 5. 你的权利

你可以随时要求查看或删除你在卡奴里的数据。删除后游戏进度无法恢复，已经兑换到旺财的金币不受影响。请通过第 7 节的方式联系，我们会在合理时间内处理。

你也可以在 Discord 的"设置 → 已授权的 App"里随时撤销卡奴的授权。

## 6. 未成年人

卡奴遵循 Discord 的年龄要求，不面向未达到 Discord 最低使用年龄的人，也不会有意收集他们的信息。

## 7. 联系方式

在大洋洲玩家游戏社区 Discord 服务器内联系卡奴管理员，或在 [GitHub](https://github.com/JoeyChen-exploration/kanu/issues) 提 issue（不要在 issue 里写个人信息，我们会另外联系你）。

## 8. 政策变更

政策更新时会修改本页的生效日期，重大变更会在服务器内通知。

# KANU Privacy Policy (English)

Effective date: November 17, 2026

KANU is a card-shop management game that runs as a Discord Activity, developed and maintained by an individual developer and available only in the "OCE Chinese Gaming Community" Discord server.

1. **What we collect.** With your authorization (OAuth2 scopes `identify` and `guilds`): your Discord user ID, username or display name, and avatar; and your server list, which is **only used to check that you are a member of the community server and is not stored**. We also store the game data you create (credits, reputation, cards and inventory, appraisal results, upgrade progress, trades, exchange records) and an activity log used for debugging, accounting and anti-cheat. We do **not** collect email, phone number, real name, location, chat or voice content, and we use no tracking cookies, ads or third-party analytics.
2. **How we use it.** To log you in and save progress; to run the game rules; to post game events in server channels (for example your display name and the card when you pull a rare card) and send game-related DMs (for example rent reminders); and to debug, reconcile accounts and prevent cheating.
3. **Sharing.** When showing your server-coin balance or converting credits into server coins, KANU sends your Discord user ID and the amount to the server's bot ("Wangcai"), which is operated by the server operator under the server's rules. Discord processes data under its own [privacy policy](https://discord.com/privacy) when KANU uses Discord's APIs. We do **not** sell, rent or share your data with anyone else, except where required by law.
4. **Storage and retention.** Data is stored on KANU's server (the same machine that runs the server operator's bot) and is accessible only to the developer and authorized server admins. Game data is kept while KANU runs; seasonal progress resets each season, while collection records and logs are kept. Daily database backups are kept for 14 days.
5. **Your rights.** You may ask to see or delete your KANU data at any time (deletion cannot be undone; coins already converted are not affected). You can also revoke KANU's access in Discord under Settings → Authorized Apps.
6. **Children.** KANU follows Discord's age requirements and is not directed at anyone below Discord's minimum age.
7. **Contact.** Contact the KANU admins in the community Discord server, or open an issue on [GitHub](https://github.com/JoeyChen-exploration/kanu/issues) (do not include personal information; we will follow up privately).
8. **Changes.** Updates change the effective date on this page; significant changes are announced in the server.
